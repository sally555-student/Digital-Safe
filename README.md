Digital Safe – Logic Gates

A simple digital lock designed and simulated using Logisim.

Project Overview

This project implements a basic digital safe using logic gates. The system checks the entered combination and controls access based on whether the correct input is provided.

Features

- 🔐 Combination-based digital lock
- 🟢 Green LED turns on when the correct combination is entered
- 🚫 Three consecutive incorrect attempts trigger a lockout
- ⏱️ The system remains locked for 10 seconds after three incorrect attempts
- 💡 Designed and simulated entirely in Logisim

Tools

- Logisim

Concepts Applied

- Logic Gates
- Boolean Logic
- Digital Circuit Design
- Input Verification
- Sequential Logic
- Counter / Timing Logic

Project File

"Digital-Safe.circ" — Main Logisim circuit file.

How to Run

1. Open the project in Logisim.
2. Load "Digital-Safe.circ".
3. Enter the combination using the circuit inputs.
4. The green LED indicates successful access.
5. After three incorrect attempts, the circuit enters a 10-second lockout period.

Purpose

The project was developed to apply digital logic concepts to a practical access-control system and gain hands-on experience in designing and simulating digital circuits.
